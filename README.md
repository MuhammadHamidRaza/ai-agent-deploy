# AI Agent Deploy

My learning project to deploy an AI agent system to the cloud.

## Goal
Containerize a FastAPI agent with a database, set up CI/CD,
and deploy it on AWS, then Kubernetes.

## Roadmap
- [ ] Week 1: Linux basics
- [ ] Weeks 2-3: Docker

- [ ] Weeks 9-11: Kubernetes
- [ ] Week 12: Kafka
- [ ] Week 13: Monitoring
- [ ] Week 14: Security and cost
