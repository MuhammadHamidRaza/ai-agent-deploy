## Command cheat sheet
| Command | What it does |
|---|---|
| pwd | shows where I am |
| ls | lists files |
| ls -l | lists files with details and permissions |
| cd folder | goes into a folder |
| cd .. | goes up one folder |
| mkdir name | creates a folder |
| touch file | creates an empty file |
| echo "text" > file | writes text into a file |
| cat file | shows file contents |
| cp a b | copies a file |
| mv a b | moves or renames a file |
| rm file | deletes a file (no recycle bin) |
| rm -r folder | deletes a folder and its contents |
| man command | opens the manual |
| command --help | shows quick help |
